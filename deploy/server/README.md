## Открыть с собственного компьютера

```sh
ssh -a -NT -i ~/.ssh/tramcast_gpu -p 1337 \
  -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes \
  -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 \
  -L 127.0.0.1:18080:127.0.0.1:8080 bazevv@89.111.142.222
```

Пока команда работает, открыть `http://127.0.0.1:18080`.
SSH-ключ остаётся только на клиентском компьютере. Публичный вход не настроен.

## Управление на сервере

```sh
systemctl --user status tramcast-app tramcast-postgres tramcast-ml
journalctl --user -u tramcast-app -n 50 --no-pager
systemctl --user restart tramcast-postgres tramcast-app
curl --fail --retry 10 --retry-connrefused --retry-delay 1 http://127.0.0.1:8080/readyz
python3 ~/tramcast-app/verify.py
```

Проверка [verify.py](verify.py) только читает HTTP, БД и состояние служб.
Остановка приложения: `systemctl --user stop tramcast-app`.
Она не удаляет БД или кэш. Удалять `pgdata` для обновления кода нельзя.

Для следующего выпуска: получить новый чистый master, проверить необходимость
Unix-патча, собрать и протестировать четыре Go-команды и фронтенд, сделать
резервную копию БД, остановить приложение, применить новые миграции и обновить
пути выпуска в `app.env` и unit-файле. Секреты не копировать в Git.
ML-комплект и активную версию менять только согласованно, затем повторить проверку.
