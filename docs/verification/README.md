## Повторение

Выполнить [CPU-запуск](../../RUN.md), затем из корня репозитория с Python 3:

```sh
python3 scripts/check_release.py
docker compose restart backend ml postgres
python3 scripts/check_release.py
```

После перезапуска дождаться доступности `/readyz`. Скрипт завершится ненулевым
кодом при расхождении или ошибке. Он рассчитан на конкурсный CPU-комплект;
для новой версии данных нужен новый эталон. `--url` задаёт адрес проверяемого
приложения. При локальной проверке использовался `http://127.0.0.1:18081`.

Самостоятельные проверки Python runtime внутри уже собранного образа
(из корня репозитория, POSIX shell):

```sh
docker run --rm --network none -v "$PWD/ml:/app/ml:ro" --entrypoint sh tramcast-ml-cpu:local -c 'cd /app/ml/runtime && python -m tests && python -m tests.test_cpu'
```

Тестовые файлы берутся из репозитория: в рабочий образ они не входят.
Каталог `ml` подключён только для чтения, сеть выключена.
Все проверки завершились с кодом 0.
