# Проверка CPU-поставки, 27 сентября 2026

Работающий удалённый сервер не переключён по просьбе пользователя.
Проверена локальная поставка: Python 3.12/macOS ARM64 и Docker/Linux ARM64.
Это проверка выполнения, а не новый замер качества на закрытом тесте.

- Нативный CatBoost без установленных torch, TabPFN и TimesFM.
- Холодный дочерний вычислитель: 1,03 с на Mac и 0,92 с в Docker;
  включает запуск Python, загрузку модели, расчёт и запись CSV.
- CSV побайтово совпадает с CPU submission, получившим от пользователя 0.88362.
- Проверены 14 640 значений через gRPC, единая версия, точная сетка, нули,
  остановочные суммы, отказ за границами горизонта, повторное чтение кэша
  после перезапуска, новое поколение и отклонение испорченного checksum.
- Docker-проверка модели выполнена с `--network none`, без GPU и lab.
- Стандартный Compose-запуск `ml-cpu` прошёл healthcheck и реальный запрос
  полного горизонта маршрута 50; `--describe` подтвердил CPU-версию.
  Временный проверочный контейнер и его кэш удалены.
- Общий набор runtime-проверок прошёл, включая прежние replay 002/030,
  отмену дочернего вычислителя, конкурентный кэш и остановочный контракт.

Результаты: [Mac](native.json), [Docker](docker-arm64.json),
[общий контракт](contract-checks.txt). ID модели зависит от платформы;
для регистрации backend всегда берите `service.py --describe` на целевом хосте.

Повторить реальный CPU-тест из `ml/runtime`:

```sh
PYTHONPATH=generated CUDA_VISIBLE_DEVICES='' ../.venv-cpu/bin/python -m tests.test_cpu
```

Требуются установленные веса и `requirements-cpu.txt`; ожидаемая контрольная
сумма посылки закреплена в тесте. Веса не хранятся в Git.
