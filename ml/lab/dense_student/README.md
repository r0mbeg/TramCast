# Расширенная дистилляция 030 на CPU

Эксперимент отделён от runtime. GPU генерирует почасовые цели для еженедельных
дат начала прогноза; CatBoost/LightGBM учится по этим целям и, в части вариантов,
по реальным наблюдениям. Учитель не является признаком ученика и не вызывается
при выдаче. Проверяемый протокол — [PROTOCOL.md](../artifacts/dense_student_20260927_v2/PROTOCOL.md).

## Обучение

GPU-скрипт `teacher.py` запускается в существующем лабораторном окружении 030
(артефакты родителей, закреплённые веса TimesFM/TabPFN и их зависимости).
`teacher.sbatch` ограничивает запуск одной GPU и двумя CPU. Выходы и родительские
кэши сохраняются в новом каталоге; старые опыты не меняются. Для каждого старта
история физически обрезается по cutoff. Новый год требует нового датасета;
этот эксперимент не доказывает перенос за пределы 2025 года.

CPU-окружение — существующий `../cpu_forecast/requirements-lightgbm.txt`.
Из корня репозитория:

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv-boost/bin/python -m ml.lab.dense_student.train \
  --teachers ml/lab/artifacts/dense_teacher_20260927_v2/teachers \
  --output ml/lab/artifacts/dense_student_20260927_v2
```

Каталог вывода должен содержать заранее зафиксированный `PROTOCOL.md` и не
содержать завершённую `selection.json`. Скрипт не перезаписывает обученные bundle.

## CPU-прогноз

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv-boost/bin/python -m ml.lab.dense_student.model \
  --bundle ml/lab/artifacts/dense_student_20260927_v2/bundle \
  --history ml/lab/artifacts/hourly_clean.csv --start 2025-11-01 \
  --output /tmp/tram-dense-prediction
```

Выход: `submission.csv` и `forecast.json` с ограничениями. Пакет содержит нативные
веса и JSON с внешними снимками и параметрами; история передаётся отдельно.
Ни GPU-библиотеки, ни файлы учительских прогнозов для выдачи не нужны.

Основной протокол допускает псевдоцели на будущие даты, если GPU рассчитала их
по истории до старта CPU-прогноза. Реальные будущие наблюдения запрещены.
Отдельная `purged_transfer` проверка исключает также будущие псевдоцели.
Сравнивать эти режимы как одинаковую задачу нельзя. Финальные веса знают историю
по октябрь; запросы для более ранних дат ретроспективны. Погода — ретроспективный
внешний сценарий ERA5, не прогноз погоды, доступный в прошлом. Качество раннего
2025, 2026 и произвольно изменённой истории не подтверждено.

Для выполненного опыта CPU-работа разделена на `--phase development` и
`--phase finish`. Первый этап требует все учительские старты до конца июня;
второй сверяет хеши исходников и входов первого этапа, читает зафиксированный
выбор и требует полный набор из 31 старта. Между этапами код и `PROTOCOL.md`
изменять нельзя. Общий CPU-бюджет — 1800 секунд; время GPU учитывается отдельно.

Проверка исправления сезонного родителя из `ml/lab`:

```sh
PYTHONPATH=. ../../.venv-boost/bin/python -m dense_student.check_regime
```

## Границы изменения контекста учителя

[Опыт v3](../artifacts/dense_student_20260927_v3/PROTOCOL.md) добавляет две новые
GPU-даты и четыре сохранённых месячных прогноза: всего 37 дат. Необязательный
признак `completed_teacher_windows` считает завершённые месячные 61-дневные
окна по календарю; GPU и её прогнозы для вычисления признака не нужны.
Старые веса без этого признака загружаются с прежним набором признаков.

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv-boost/bin/python -m ml.lab.dense_student.boundary_train \
  --boundaries ml/lab/artifacts/boundary_teacher_20260927_v1 \
  --output ml/lab/artifacts/dense_student_20260927_v3
```

Для нового запуска требуется отдельный каталог с копией закреплённого PROTOCOL.md.
Используется выбранный v2 CatBoost без нового подбора. Финальная компрессия
включает точный ноябрьский учительский прогноз; его fidelity является обучающей.
Августовский отложенный origin проверяет ретроспективную интерполяцию года,
а не прогноз из прошлого. Сентябрьская диагностическая проверка уже просмотрена.

Проверка отдельного CPU-процесса после обучения:

```sh
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv-boost/bin/python \
  -m ml.lab.dense_student.check_portable \
  --run ml/lab/artifacts/dense_student_20260927_v3 \
  --history ml/lab/artifacts/hourly_clean.csv
```
