# Происхождение расширенных учительских целей

GPU: Zhores `gpu_devel`, одна выделенная GPU, два CPU. Исходная история и
веса закреплены SHA256 в `started_*.json`; версии библиотек там же.
Старые исследования и deployed runtime не изменены.

- 8477205: пилот cutoff 2025-05-07, 41 секунда.
- 8477206: известный cutoff 2025-05-31 и недельные апрель–май. Известный
  прогноз после half-up совпал во всех 14640 строках с сохранённым 030.
  Остановка на 2025-06-04 из-за отсутствующих летних weekday-групп.
- 8477207: продолжение с недостающими июнь–октябрьскими датами. В родительском
  сезонном профиле только отсутствующие группы дополняются историей до cutoff.
  Действующий 030 не меняется; новый набор точнее обозначать семейством 030.

Регрессионная проверка `dense_student/check_regime.py` воспроизводит старый
сбой на 4 июня, подтверждает конечный полный выход после исправления и
неизменность результатов для 31 мая и 31 августа. Полная будущая история
и обрезанная история дают одинаковый исправленный родительский прогноз.

Каждый CSV имеет JSON с origin, end, history_max, SHA256, длительностью и
ссылкой на манифест исходников. Данные — прогнозы, не реальные наблюдения.
Старые месячные родительские кэши переиспользуются только для завершённых
61-дневных окон; новые внешние прогнозы пересчитываются для своего cutoff.
Параметры 030 ранее выбраны ретроспективно; новый набор не устраняет это ограничение.

`teacher_source_v2.py` — генератор до исправления сезонного fallback.
`source_snapshot/experiments/` — точные исходники окружения GPU, которые могут
отличаться от текущего локального дерева. Веса и рабочие кэши не копируются в Git.
