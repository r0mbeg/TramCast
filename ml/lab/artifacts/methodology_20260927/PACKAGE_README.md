# TramCast ML: пакет для интеграции

Это самостоятельная поставка **обслуживания сохранённого прогноза Chronos002**
по gRPC и документов исследования. GPU, исходные CSV и веса модели для запуска
сервиса не нужны. Backend/frontend в архив не входят. Пакет не обещает
произвольные даты, годовую точность, остановочный прогноз или заполненность.

## Запуск

Из каталога, куда распакован архив, Python3.12:

```sh
python3 -m venv ml/.venv
ml/.venv/bin/python -m pip install -r ml/requirements-service.txt
PYTHONPATH=ml/generated:ml ml/.venv/bin/python ml/service.py --bind 127.0.0.1:50051
```

Во втором терминале:

```sh
PYTHONPATH=ml/generated:ml ml/.venv/bin/python ml/client.py \
  --route 1 --from 2025-11-01T00:00:00+03:00 --to 2025-11-02T00:00:00+03:00 \
  --output /tmp/tramcast-day.json
```

Все пути относительны корню распакованной поставки. Произвольный порт задаётся
`--bind` сервера и `--address` клиента. На Windows использовать синтаксис
переменных своей оболочки, при необходимости установить tzdata.

## Документы и проверка

- `ml/INTEGRATION.md` — API, версии, ошибки, периоды, агрегаты и сценарии.
- `ml/forecast_bundle.json` — фактические версии и контрольная сумма CSV.
- `proto/` — общий контракт; Python generated-код уже включён.
- `ml/artifacts/methodology_20260927/REPORT.md` — выводы и ограничения.
- Вложенные `route/data/review` — таблицы и независимые свидетельства.
- `manifest.json` — SHA256 всех файлов поставки. Это контроль целостности,
  не цифровая подпись. Сервер дополнительно сам проверяет модельный CSV.

Проверки сервиса и клиента после установки service requirements:

```sh
cd ml
PYTHONPATH=generated .venv/bin/python -m tests.test_service
PYTHONPATH=generated .venv/bin/python -m tests.test_client
```

Docker: из корня `docker build -f ml/Dockerfile -t tramcast-ml .`.
Образ в этой проверке заново не собирался; локальный gRPC проверен.

Метрики сравнения воспроизводятся в **исходном репозитории** командами отчёта:
там сохранены история, raw-прогнозы и старые источники. Эти большие
исследовательские входы не включены в маленькую поставку сервиса. Веса и
окружение Zhores тоже не включены. Архив содержит итоговые таблицы и
происхождение, не самостоятельный комплект для повторного обучения.
Условия новых данных и перехода к рабочему остановочному прогнозу —
`data/REQUIREMENTS.md` внутри каталога исследования.
