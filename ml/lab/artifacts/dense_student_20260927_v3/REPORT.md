# CPU-дистилляция с учётом границ контекста 030

Получен самостоятельный CPU-CatBoost и [submission.csv](submission.csv) на
ноябрь–декабрь 2025. На повторно использованной локальной проверке сентября–октября
score **0,89853**, у GPU 030 **0,89964**. Это сильный кандидат для закрытой проверки,
но не доказательство SOTA: этот период уже использовался для диагностики.
Закрытый score новой посылки пока неизвестен.

## Что изменилось

Вместо редких учительских стартов собраны **37 прогнозов**, 541 680 строк полной
сетки, 406 260 активных псевдоцелей. 33 прогноза рассчитаны в этой работе,
четыре месячных результата переиспользованы из сохранённого 030. История новых
GPU-запусков физически обрезалась по cutoff; старые месячные результаты имеют
cutoff-проверки исходного рецепта, но их исходный вызов не был физически обрезан.
Это прогнозные цели, не новые фактические наблюдения.

Первая недельная версия v2 давала только 0,87666. Ученик хорошо повторял
ближайшего учителя, но между 27 и 30 августа у учителя завершалось новое
61-дневное окно калибровки. Добавлены соответствующие граничные старты и
признак числа завершённых окон. Признак рассчитывается из дат на CPU.
Для неполной первой недели лета исправлен родительский резервный профиль:
отсутствующие seasonal weekday-группы берутся из более ранней истории.
Действующий runtime 030 и старые результаты не изменены.

CatBoost: depth 7, 800 деревьев, RMSE, lr 0,05, seed 42, два CPU-потока.
Параметры и равные суммарные веса учительских/реальных целей выбраны ранее
по маю–июню и июлю–августу; в v3 нового поиска параметров не было. Входы —
исторические календарно-часовые профили, календарь, движение, школьный календарь,
погода и доступный контекст учителя. Прогнозы учителя не являются входами
при выдаче. Погода — ретроспективный ERA5-сценарий, не прогноз погоды из прошлого.

## Локальные результаты

Одинаковая маска 10 708 наблюдаемых активных часов, после half-up и структурных нулей:

| Модель | MAE | WAPE | Score |
|---|---:|---:|---:|
| CPU-CatBoost без дистилляции | 169,62 | 0,14266 | 0,85734 |
| Предыдущий LightGBM Laplace | 147,72 | 0,12424 | 0,87576 |
| Недельная дистилляция v2 | 146,64 | 0,12334 | 0,87666 |
| **Граничная дистилляция v3** | **120,64** | **0,10147** | **0,89853** |
| GPU 030 | 119,33 | 0,10036 | 0,89964 |

Реальные цели оценочного обучения заканчиваются 31 августа. Самый поздний
учитель — cutoff 30 августа; точный учитель cutoff 31 августа не входил в fit.
Учительские прогнозы могут покрывать будущие даты, но не используют будущие
реальные цели. В v2 строгая проверка без будущих псевдоцелей дала лишь 0,78989:
перенос без актуальных учительских примеров на будущий период не подтверждён.
Параметры самого 030 также выбирались в прежних исследованиях ретроспективно.

Сообщённые пользователем закрытые результаты: старый CPU-CatBoost **0,85630**,
старый LightGBM **0,84716**. Они не использовались как функция подбора.

## Финальная модель и сходство с учителем

Финальный fit использует 195 268 повторяющихся наблюдаемых примеров с целями
не позже 31 октября и 406 260 учительских примеров. Повторы физических
route/date/hour учитываются весами. **Точный ноябрьский прогноз 030 включён
в финальное обучение** как псевдоцель; закрытых реальных значений нет.

| Проверка | WAPE к учителю | Значение результата |
|---|---:|---|
| 1 сентября, оценочные веса | 2,162% | Точный origin учителя исключён из обучения |
| 1 ноября, финальные веса | 2,148% | Обучающее сходство, не независимая точность |
| 15 августа, финальные веса | 3,081% | Исключённый origin внутри фиксированного года; ретроспективная интерполяция |

Финальные веса знают историю по октябрь и поздние учительские прогнозы.
Их ответы на ранние даты нельзя называть прогнозами, доступными в прошлом.
API принимает любой старт 2025 и выдаёт 61 день, но качество января–марта,
2026 и произвольно изменённой истории не проверено. Предупреждения возвращаются
в метаданных. Рабочий микросервис пока не переключён на этот пакет.

## Ресурсы и проверки

Измерено на текущем Mac, два CPU-потока; это не измерение Linux-хостинга.

| Этап | Результат |
|---|---:|
| Оценочный + финальный fit v3 и проверки | 385,55 с |
| Финальное обучение | 223,02 с |
| Пик памяти обучающего процесса | 1287,97 МиБ |
| Загрузка весов и истории после импортов | 0,044 с |
| Признаки + полный прогноз, отдельный CPU-процесс | **0,107 с** |
| Пик памяти отдельного проверочного процесса | **180,53 МиБ** |
| Нативные веса | **3 081 572 байта** |

Проверены точная сетка 14640 строк, `route;date;hour;prediction`, int64,
неотрицательность, обязательные нули №5 и часов 1–4, границы счётчика контекста,
повторная загрузка весов, отказ на повреждённых весах, неизменность ответа
при подмене будущих фактов и масок, технические запросы начала/конца года.
В отдельном процессе с пустым CUDA_VISIBLE_DEVICES не загружены torch,
TabPFN или TimesFM. Старый v2 bundle даёт прежние значения с совместимым загрузчиком.
