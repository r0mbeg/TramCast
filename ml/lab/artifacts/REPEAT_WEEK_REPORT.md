# Повторение последней полной недели

**Результат: лучше опорного baseline летом, хуже осенью и в среднем. Baseline сохраняется.** Эксперимент проверяет адаптацию идеи Repeat из статьи, а не воспроизводит её событийную модель или метрики TMS/cDFS.

## Постановка

Последняя полная неделя определена до оценки как завершённые понедельник–воскресенье не позже cutoff. Это 23–29 июня при cutoff 30 июня и 25–31 августа при cutoff 31 августа. Данные 30 июня намеренно не входят в первый недельный профиль: проверяется календарная неделя, а не скользящие семь дней.

Для каждого будущего ключа берётся единственное значение того же маршрута, дня недели и часа из выбранной недели. Оно повторяется на все 62 дня июля–августа или 61 день сентября–октября. Профиль не обновляется внутри горизонта. Используется существующая функция сезонного профиля; среднее по одному наблюдению равно самому наблюдению. Неполная исходная сетка вызывает ошибку, без скрытой подстановки более старых данных.

Источник — `hourly_clean.csv`; сырые CSV повторно не читаются. Пропущенные события по действующему допущению считаются нулями, восстановление не выполняется. Правила рабочих часов, маршрута 5 и округления общие с baseline. Ноль из исходной недели также повторяется и не означает доказанного отсутствия спроса.

## Результаты на очищенной полной сетке

| WAPE-score | Июль–август | Сентябрь–октябрь | Среднее окон |
| --- | ---: | ---: | ---: |
| Среднее всей истории | 0,77915 | **0,86243** | **0,82079** |
| Последняя полная неделя | **0,80642** | 0,82324 | 0,81483 |
| Изменение | +0,02727 | −0,03919 | −0,00596 |

Метрика каждого окна — глобальный WAPE-score, без усреднения по маршрутам или часам. Последний столбец — арифметическое среднее двух окон для сопоставления с прежним выбором модели, не единый WAPE по объединённым наблюдениям. Ранее проверенное среднее четырёх недель летом даёт 0,81765, то есть превосходит и повторение одной недели.

| Показатель | Лето: среднее истории | Лето: неделя | Осень: среднее истории | Осень: неделя |
| --- | ---: | ---: | ---: | ---: |
| Абсолютная ошибка, посадки | 2 361 493 | 2 069 895 | 1 751 473 | 2 250 462 |
| Суммарное смещение относительно факта | +15,55% | +9,09% | −6,55% | −8,99% |

Летняя абсолютная ошибка уменьшилась на 291 598 посадок, осенняя увеличилась на 498 989. Летом выиграли 8 из 9 непустых маршрутов, осенью ухудшились 8 из 9; исключение в обоих случаях — маршрут 17. Маршрут 5 получает только обязательные нули, обученное качество для него не заявляется.

| Месяц | Среднее истории | Последняя неделя |
| --- | ---: | ---: |
| Июль | 0,76434 | 0,79510 |
| Август | 0,79423 | 0,81794 |
| Сентябрь | 0,87219 | 0,83326 |

Более свежая неделя уменьшила летнее завышение, но усилила осеннюю недооценку. Это согласуется с ограничением переноса последнего режима на следующие два месяца, однако эксперимент не отделяет сезонный сдвиг от шума конкретной недели. Он не обосновывает выбор разных методов задним числом для каждого окна. Оба окна многократно использовались для разработки и не являются независимой финальной оценкой. Скрытое качество ноября–декабря неизвестно.

## Воспроизведение и проверки

```sh
python test_pipeline.py
python pipeline.py repeat-week
```

Тест с известными различающимися значениями проверяет источник каждого прогноза на всём горизонте обоих окон, включая cutoff в понедельник и воскресенье. Изменение всех данных вне исходной недели не влияет на прогноз; неполная неделя отвергается. Сохранились проверки агрегации, округления, WAPE и обязательных нулей. `python test_model.py` также прошёл.

При запуске опорный baseline пересчитывается и сверяется с сохранёнными исходными результатами. Прогнозы присоединяются по ключам, проверяются размер сетки и обязательные нули. Экспорт перечитан и сравнен с исходной таблицей полностью.

- `repeat_week_metrics.csv`: четыре результата, границы исходных периодов, основные метрики и отдельно score на исходных неочищенных labels.
- `repeat_week_breakdown.csv`: ошибки по маршрутам, часам и месяцам.
- `repeat_week_predictions.csv`: факты и прогнозы обоих методов на полной сетке каждого окна.
- `repeat-week_run.json`: SHA-256 истории, параметры, признаки, версии, время и пиковая память. Метод детерминированный, seed не требуется.

Два окна и сравнение заняли **14,54 с**, пиковая память процесса **145,5 MiB**, Python 3.12.14, pandas 2.2.3, numpy 2.3.5. Это время полного запуска оценки с чтением и проверкой экспорта, не latency инференса. Прежние артефакты и submission не перезаписывались; финальная модель не менялась.
