# OT20260927-v1: проверка географического сигнала оптимальным транспортом

Протокол записан до запуска 27.09.2026. Гипотеза: неодинаковые расстояния
между последовательными остановками несут узнаваемый временной рисунок;
частичный OT может восстановить его по регистрациям без GPS. Это проверка
гипотезы, не обещание остановочной точности и не новый рецепт 030.

- Только будни 15–19 сентября: выходной вариант маршрута не установлен.
  Родительский набор уже отобран по активности обоих наборов валидаторов;
  результат относится к этой условной выборке. Полнота регистраций неизвестна.
- Из reference доступны только первые 240 ячеек (40 минут). Сгладить их

  количество. Нулевые тестовые счётчики не дают score, но час не удаляется.
  Неделя ранее исследовалась; это новая задача на просмотренных данных,
  не независимый тест и не прогноз на 61 день.

## Частичный транспорт

Одна единица массы = один reference-пик или одно гипотетическое посещение,
**не пассажир**. Неизвестные остановочные массы посадок не фиксируются.
Для времён пиков t и посещений u решить

`min Σ Pij*((ti-uj)/30)^2 + 4*(m-ΣP) + 0.25*(n-ΣP)`

при `P≥0, P1≤1, Pᵀ1≤1`. Это частичный OT с линейными штрафами за
несопоставленную массу. Бипартитная задача имеет целочисленный оптимум;
достаточно существующего scipy.optimize.linear_sum_assignment с dummy
столбцами. Квадратичная стоимость допускает оптимальное сопоставление без
пересечений. Фиксированный штраф за пропуски — допущение, не измеренная
вероятность посещения. Все посещения допустимы, но exit-only не дают
посадочных пиков и в транспорт/прогноз регистраций не входят.

546 гипотез: 91 начальная позиция × скорость {10,15,20} км/ч × стоянка
{0,15} с, плюс 60 с на условном развороте. Первому reference-пику условно
соответствует начальная позиция; возможны посещения до него. По времени
перегона нижний предел 1 с. Постоянная скорость в пределах часа — сильное
ограничение пилота. Гипотезы усредняются с весом exp(-OT_cost), температура 1.
Это Gibbs-веса, не калиброванный posterior и не энтропийный Sinkhorn.
Для будущего хвоста: Gaussian-пики sigma=45 с у посадочных позиций,
нормировка на 120 ячеек, 10% равномерной примеси. Гипотеза без будущих
посадочных посещений даёт равномерную плотность. Средние/максимальные веса
гипотез — только диагностика концентрации.

## Контроли и критерий

1. Равномерная временная плотность хвоста.
2. Такая же OT-модель с одинаковыми расстояниями всех неразворотных рёбер;
   общая длина цикла, развороты и посадочная поддержка сохраняются.
3. 19 моделей со случайно переставленными длинами неразворотных рёбер внутри
   каждого направления. Те же гиперпараметры, начальные позиции и вычисления;
   перестановки фиксирует seed=20260928. Сохраняется распределение длин,
   разрушается географический порядок. Это суррогатные контроли, не строгая
   нулевая модель случайной московской сети и не основание для p-value.

Основной score = Σ held_bin*log(predicted_bin_probability)/Σ held_bin,
нат/событие, больше лучше. Сохранить результаты каждого контроля и часа,
дневные срезы, описательный bootstrap по vehicle_day (1000, seed=20260927).
Обычные общегородские зависимости дней bootstrap не устраняет.
Условие продвижения: настоящая геометрия лучше uniform и equal-spacing,
лучше всех 19 перестановок, нижняя граница bootstrap выигрыша относительно
среднего score перестановок >0. Даже выполнение всех условий не измеряет
точность имён остановок и не разрешает превращать сопоставления в факты.

CPU-бюджет: один запуск ≤15 минут, без поиска гиперпараметров по хвосту.
При превышении сохранить сбой; не уменьшать выборку по увиденным score.
Выход — новый каталог runs/optimal-transport-20260927-v1, код, checks,
manifest и отчёт. Никаких изменений старых результатов, runtime или Go/UI.

## Основания и границы

Изучены 27.09.2026:

- [Singh et al., 2020](https://arxiv.org/abs/2003.13933): структурный
  multi-marginal OT для вывода по агрегированным наблюдениям в графе.
- [Yang & Zha, 2022](https://arxiv.org/html/2212.14527v1): inverse MOT
  для меняющихся переходов. Их агрегаты содержат распределения по состояниям;
  одна маршрутная сумма таких ограничений не даёт.
- [Janati et al., 2020](https://proceedings.mlr.press/v108/janati20a.html):
  сочетание временного выравнивания и unbalanced OT; изучена страница авторов
  в PMLR. Наш пилот не воспроизводит STA и не реализует Gromov–Wasserstein.
- [González-Sanz et al.](https://arxiv.org/abs/2410.23146):
  идентифицируемость стоимости inverse OT зависит от наблюдаемой информации;
  изучено резюме версии v4. Не переносим их теоремы автоматически на TramCast.

Маршрутный итог T задаёт лишь Σxi=T: при n разрешённых позициях остаётся
n−1 степеней свободы. Если в OT задать обе маргинали a и b, результат P
обязан иметь остановочную сумму b — она задана исследователем, а не выучена.
Предложенный опыт ищет дополнительную информацию во временах событий.
Конечная цель остаётся «позиция × дата × час»; в случае успеха нужен отдельный
опыт переноса временного сигнала в доли, без подмены наблюдений оценками.
