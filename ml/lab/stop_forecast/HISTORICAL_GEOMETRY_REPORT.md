# H20260927-v1: историческая география №12

Получен отдельный набор остановочных последовательностей через исторические
запросы OpenStreetMap на **15 и 22 сентября 2025, 00:00 UTC**. Это продвижение
от декабрьского справочника к географии исследуемого периода. Историческое
состояние карты ещё не подтверждает фактический путь каждого рейса.

## Получение и происхождение

Вызвано открытое зеркало Overpass, уже используемое проектом:
`https://maps.mail.ru/osm/tools/overpass/api/interpreter`.
Поиск отношений `route=tram, ref=12` в границах Москвы вернул два ID:
14258874 и 14258875. Затем на две даты выгружены эти отношения и их
остановочные/платформенные узлы, только `out body`, без сведений об авторах правок.

Три неизменённых ответа сохранены в
`dataset/external/route12_osm_history_20260927/`, вне Git. Точные запросы,
URL, время получения, размеры, SHA256 и неудачные обращения перечислены в
[реестре источника](sources/route12_osm_history_20260927.json).
Данные © участники OpenStreetMap, ODbL 1.0; атрибуция сохранена в ответах.

По [документации Overpass](https://dev.overpass-api.de/overpass-doc/en/analysis/museum.html)
параметр `date` выбирает состояние базы на указанную дату.
`timestamp_osm_base` в ответе — время обновления сервера в 2026 году,
оно не заменяет запрошенную историческую дату. Дополнительный контрольный
запрос на 2020 год не завершился: HTTP 504, повтор — таймаут. Поэтому
историческая интерпретация опирается на контракт API; независимое подтверждение
работы фильтра другой выгрузкой не получено. Основной сервер вернул HTTP 406,
второе зеркало — таймаут. Это ограничения конкретных обращений, не доказательство
отсутствия истории у источников.

## Что подготовлено

| Показатель | Значение |
| --- | ---: |
| Направление Восточное Измайлово → МЦК Дубровка | 46 позиций |
| Обратное направление | 45 позиций |
| Всего остановочных позиций | 91 |
| Роли OSM: обычная / только посадка / только высадка | 87 / 2 / 2 |
| Позиции в декабрьской книге | 97 |
| Пары в пределах 100 м, с одинаковым направлением | 85 |
| Позиции книги без кандидата в пределах 100 м | 12 |
| Исторические позиции без кандидата в пределах 100 м | 6 |

Числовые направления 0/1 назначены по конечным пунктам и сопоставлены с книгой;
это не исходный тег `direction_id` OSM. Позиция хранит ID отношения, исходный
индекс участника, порядковый номер остановки и роль. Повторение одного узла
в разных местах последовательности не объединяется. `stop_exit_only` помечен
как не разрешающий посадку **по данным OSM**, а не по наблюдениям валидатора.

На границах недели все 165 элементов двух ответов совпали: 2 отношения и
163 узла (включая платформы). Равенство границ не доказывает отсутствия
временных изменений внутри недели. Для текущих данных сохранён именно этот
предел, без автоматического распространения схемы на каждый час.

100 м — фиксированный поисковый радиус для кандидатов, не измеренная ошибка
и не критерий доказанного тождества. В каждой позиции книги не более одного
кандидата в этом радиусе; это не гарантирует взаимно однозначного соответствия.
12 несовпадений включают конечные, Вольную улицу, Семёновскую, Абельмановскую
Заставу и другие позиции. Например, ближайшая историческая позиция к
Абельмановской Заставе из книги удалена примерно на 306 м. Причины различий
не установлены: изменение остановки, представление конечной, неточность
координат или неполнота источника. Полная таблица сохранена без слияния ключей.

## Что ещё блокирует использование как разметки

[Официальная публикация 02.06.2025](https://transport.mos.ru/mostrans/all_news/124737)
объявляет с 7 июня по выходным направление №12 к МЦД Новогиреево через
проспект Будённого; по будням — обычный маршрут. В полученном тексте нет даты
окончания. Источник прочитан через индекс поиска, прямое открытие не удалось.
OSM-схема к Дубровке не описывает объявленный выходной вариант. Применимость
объявления к 20–21 сентября и полный календарь исключений не подтверждены.

В тегах OSM найден [официальный URL расписания №12](https://transport.mos.ru/transport/schedule/route/141501939),
но его открытие не удалось. Историческое расписание, выполненные рейсы и
соответствие вагонов рейсам не получены. Даже плановое расписание не было бы
эталоном фактического времени прибытия.

Таким образом, H-v1 содержит **географические признаки и кандидаты соответствия**,
не метки посадок. Подтверждённых привязок по-прежнему 0, MAE/WAPE остановок
не определены. Сценарный опыт C-v1 не переписан. Повторять его под видом
проверки точности на этих же неподтверждённых остановках нельзя.

Следующий вход для измеримого улучшения — хотя бы независимая выборка
`timestamp Europe/Moscow, vehicle_id, route, pattern/direction, stop_id/coordinates,
event_type (arrival/departure), source, timestamp/location uncertainty`,
плюс подтверждённая связь `device_no ↔ vehicle_id` с периодом действия.
Её нужно разделить по дням/вагонам на якоря модели и скрытую проверку.
Официальные данные о временных вариантах также нужны отдельно. Никаких
обращений владельцам данных или сообщений третьим лицам не отправлялось.

## Воспроизведение и проверка

```sh
# Получение каждой копии: соответствующие query/output перечислены в реестре.
curl --fail --max-time 45 -A 'TramCast/0.1' \
  https://maps.mail.ru/osm/tools/overpass/api/interpreter \
  --data-urlencode 'data@ml/lab/stop_forecast/sources/route12_osm_queries/start.overpassql' \
  -o /tmp/route12-history-start-new.json

.venv/bin/python ml/lab/stop_forecast/test_historical_geometry.py
.venv/bin/python ml/lab/stop_forecast/historical_geometry.py --out /tmp/tramcast-historical-geometry-new
```

Повторное скачивание сохранять как новую версию: сервер может исправить данные,
а обёртка ответа содержит новое время обновления. Для точного повтора нужны
исходные снимки с SHA256 из реестра и C-v1 как неизменённая точка сравнения.

Выход `runs/historical-geometry-20260927-v1/`: `historical_occurrences.csv`,
`catalog_candidates.csv`, `catalog_coverage.csv`, `summary.json`, `manifest.json`.
CSV локальные; компактные результаты и хеши доступны для ревью.
Проверены повторяющиеся узлы, роли посадки/высадки, отклонение неполного ответа,
отсутствующих узлов, некорректных координат и метаданных редакторов.
