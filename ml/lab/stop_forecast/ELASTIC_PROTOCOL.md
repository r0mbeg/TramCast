## Обучение и модель

Переиспользовать `activity_model.fit`: по целым reference-блокам обучения
совместно оценить три параметра NB-duration HSMM (контраст, длительности
низкой/высокой активности), прежние priors, bounds, 3 старта. Контрольные
устройства не участвуют. Это общие параметры многих вагонов, без выученных
остановочных интенсивностей и без доказательства физического смысла режимов.

Географический sparse HMM: позиция × относительный темп {0.67,1,1.5} × фаза
{регистрация, движение-1, движение-2}. Две фазы движения дают сумму двух
геометрических длительностей. Среднее регистрации = обученное высокое;
среднее движения = length/(base_speed*tempo)+60*turn, минимум 20 с.
`base_speed = sum(length)*mean(1/tempo)/(n*learned_low_seconds-60*turn_count)`.
Это эффективная шкала времени, не измеренная скорость. Граница 20 с и
геометрические фазы — явно фиксированные приближения NB-duration baseline.

Переход темпа только на следующей позиции:
`Q = persistence*I + (1-persistence)*ones/S`.
Переход по позициям только вперёд, обе конечные соединены условно. Вероятность
перехода из каждой фазы за ячейку = 10/mean_seconds. Начальная фаза неизвестна,
начальное распределение стационарно (масса ∝ средней длительности фазы).
На exit-only нет повышенного режима оплат. Высокий/низкий контраст взят из
fit; стационарная средняя относительная интенсивность нормируется к 1.
Масштаб каждого блока — только reference первого часа, неизменен далее.

Проверить persistence {0,0.9} на **equal-spacing** географии по скрытым
reference-участкам validation, выбрать по log score. Выбор общий для всех
географий, записать selection.json до оценки held и тестовых дней.

## Маски, контроли и критерий

В каждой трёхчасовой записи скрыты reference-участки минут [60,62), [80,82),
[100,102), [120,122), [140,142), [160,180). Фильтр продвигается вперёд без
наблюдений в этих интервалах, после промежуточного окна продолжает получать
reference; обратного сглаживания из будущего нет. Фаза не сбрасывается на
границе часа или скрытого окна. Непрерывность здесь — наблюдаемого потока,
не доказанный непрерывный рейс.

Предсказывается временная плотность из ожидаемой интенсивности HMM с 10%
uniform-примесью, отдельно нормированная внутри каждого скрытого окна.
Score = Σ count*log(probability), затем /Σ count. Это условное распределение
времён, не предсказание числа оплат. Основная цель — события held в пяти
коротких окнах; отдельно те же окна reference и оба устройства в хвосте 20 мин.
Информация новых reference после окна может использоваться только для
следующих окон. Начальный масштаб не читает ни одного скрытого счётчика.

Контроли с теми же масками: uniform; исходная обученная NB-duration HSMM без
географии; equal-spacing с переменным темпом; историческая схема с единственным
темпом 1 (ablation); 19 перестановок длин внутри направления без разворотных
рёбер (seed=20260929), каждая со своим правильным временным масштабом и теми
же обученными параметрами. Перестановки сохраняют распределение расстояний;
это суррогаты, не строгий статистический permutation test.

Критерий продвижения исторической переменной модели: основной held score
лучше uniform, NB-HSMM, equal-spacing и всех 19 перестановок; нижняя граница
описательного bootstrap по вагон-дням к среднему score перестановок >0.
Сохранить дневные срезы, оба горизонта и все модели независимо от результата.
Отдельно оценить выигрыш переменного темпа против фиксированного. Не объявлять
критерий выполненным только из-за успешной реконструкции reference.

Никаких остановочных обучающих меток/долей/пакета не выпускать по этому опыту.
stop MAE/WAPE остаются null без независимого эталона. Все старые исходники,
результаты и 030 сохраняются. Историческое ядро не менять: для sparse HMM
использовать тот же масштабированный forward-вывод и сверить его с точным
`duration_model.infer` на малом примере.
