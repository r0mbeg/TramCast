# E20260927-v1: пакет расчётных оценок №12

Зафиксирован до реализации/выпуска. Это интеграционный сценарий, не новый
эксперимент по точности. Никакой подбор по будущим целям или stop score.

- Маршрут 12, 01.11–31.12.2025, 1464 часа, зона Europe/Moscow.
- Источник целых маршрутных итогов — `ml/bundles/030/forecast.csv` с проверкой
  SHA256 из `forecast_bundle.json`. Это replay существующего GPU-результата,
  не новый вызов 030. Ночные нули сохраняются.
- Схема — 97 позиций очищенного каталога приложения, два направления,
  по одному шаблону на направление. Полное совпадение ключей с F-v2 обязательно.
  Историческая применимость не подтверждена: start_date 20.12.2025,
  actual_date 05.02.2026. Условно используем весь снимок на всём горизонте.
  Неизвестный смысл stop_mode сохраняется, посадочная допустимость каждой
  позиции считается предположением. Нет утверждения о реально выполненных рейсах.
- Исходные s — доли модели B-v4, обученной по московским маршрутным суммам,
  из F-v2 `scenario_profiles.csv.gz` (uniform, strength=0). Не stop truth.
  q_i=1/97; lambda=1, p_i пропорциональны sqrt(s_i*q_i).
  Это minimizer KL(p||s)+KL(p||q). Переиспользовать entropy_projection.
  Выбор lambda инженерный, сохранён из F-v2, не оптимален по измеренной точности.
- 40 контекстов: рабочие часы 0,5–23 × будни/сб-вс. Ни календарные праздники,
  ни фактический выпуск не известны модели. Все направления нормируются вместе.
- Округление largest remainder с точной рациональной арифметикой для переданных
  весов; tie-break `(route, direction_id, pattern_key, stop_sequence, source_stop_id)`.
  Число валидаций — int64. Не повторять округление в интеграции.
- Выпуск содержит таблицы позиций, долей, оценок, маршрутных итогов/баланса,
  метаданные, диагностику чувствительности и manifest с SHA256. ID остановок
  источника не равны внутренним stop_id PostgreSQL. Join по номеру маршрута,
  pattern_key и stop_sequence, затем проверка source_stop_id на серверной стороне.
- При несовпадении снимка/неполных профилях/пропусках часов builder останавливается.
  Потребитель при частичном сопоставлении не перенормирует оставшиеся доли:
  сумма несопоставленных готовых оценок остаётся unassigned, покрытие явно падает.
- На полном совпавшем снимке unassigned=0 означает распределение по допущению,
  а не точность привязки. Verified stop observation coverage=0; WAPE/MAE=null.
- Бюджет: один выпуск, один побайтовый повтор, проверки границ/ошибок, без
  обучения, GPU, новых зависимостей и изменений backend/frontend/runtime.
- Сравнить с uniform и ранее рассчитанными lambda=0/10 и centre prior;
  это чувствительность оценок, не доверительные интервалы.

Исторические B/F и 030 не изменять. Новый пакет локальный, не опубликован,
не отправляется в конкурс. Передача файлов разработчику не является внедрением.
