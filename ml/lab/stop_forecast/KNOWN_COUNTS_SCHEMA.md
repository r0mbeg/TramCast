# Проверяемые временные счётчики K-v1

Цель — число зарегистрированных успешных валидаций №12 в 15-минутном
интервале. Это более подробная временная цель, точно вычисляемая из raw.
Остановки, направления, поездки и пассажиры не восстанавливаются.
Зона всех локальных времён — `Europe/Moscow`; интервалы полуоткрытые.

## Датасет

Локальный каталог `dataset/derived/known_counts_20260927_v1/`, вне Git.
`observations.csv`: разделитель `;`, ключ `(route, date, hour, quarter)`.
`quarter` 0/1/2/3 соответствует минутам 00–14/15–29/30–44/45–59.

| Поле | Смысл / разрешённое использование |
| --- | --- |
| route, date, hour, quarter | Ключ; известны при будущем прогнозе |
| weekday, weekend | Пн=0…Вс=6; weekend=сб/вс. Календарные признаки |
| working_minutes | 0 или 15 по согласованному рабочему окну; не uptime устройства |
| registered_successes | Точное количество подходящих строк raw; учётный ноль возможен и при отсутствии наблюдений |
| working_events | Все события рабочего интервала независимо от результата; не будущий вход модели |
| observed_counter | Обучающая цель: число успехов либо null при отсутствии наблюдений; структурный ноль равен 0 |
| counter_status | observed_unknown_completeness / missing / structural_zero |
| complete_hour | Нет missing среди рабочих четвертей данного часа; **не доказательство полной регистрации** |

Статусы и complete_hour — маски отбора обучения/оценки, а не признаки будущего
прогноза. Ноль при наличии только неуспешных событий остаётся наблюдаемым
нулём успешных регистраций. Пропуски не заполняются восстановленными целями.
`registered_successes` нужен для баланса и не должен заменять nullable target.
Код кандидатов явно выбирает тренировочные даты и complete_hour; все значения
в этих выбранных строках совпадают с observed_counter, включая структурные нули.

`hourly_observations.csv` — исходный сверенный почасовой счётчик и маски S-v2.
`manifest.json` — SHA256 обоих raw, использованного кода, протокола, аудита и
выходных файлов. Источник одинаков для строк и задаётся на уровне выпуска.
`summary.json` — покрытие и число успешных событий. Нет платёжных, вагонных
или персональных идентификаторов.

## Предсказания

`runs/known-counts-20260927-v1/predictions_<cutoff>.csv` хранит календарные
ключи и отдельный столбец каждого кандидата. `forecast.csv` — выбранный
на первом окне вариант после обучения до 31 октября: 5856 строк №12 на
1 ноября–31 декабря, все 96 четвертей каждого дня, включая структурные нули.

Ключ и working_minutes имеют смысл выше. `cutoff` — последний день истории;
`prediction` — неотрицательный целочисленный прогноз регистраций;
`model_version` — семейство K20260927-v1; `dataset_version` — версия с
префиксом SHA256 таблицы наблюдений; `selected_model` — точное имя кандидата.
Код, обученные профили, контроль 030 и выходы закреплены хешами в manifest.
Для однозначного воспроизведения нужны вместе версия, cutoff и manifest.
Прогноз исследовательский, локальный; фактических меток ноября–декабря нет.

В `results.json` разделены quarter (основная оценка на наблюдаемых часах),
hour (суммы того же среза), observed_quarters (все отдельные наблюдаемые
четверти) и oracle_distribution_only (диагностика при **известной фактической**
часовой сумме). Последнее не является результатом будущего прогнозирования.
Все WAPE хранятся долями, а не процентами; при нулевом знаменателе — null.

## Воспроизведение

Из корня репозитория; выходные каталоги должны отсутствовать:

```sh
.venv/bin/python ml/lab/stop_forecast/test_known_counts.py
.venv/bin/python ml/lab/stop_forecast/known_counts.py prepare --out /tmp/tramcast-known-data
.venv/bin/python ml/lab/stop_forecast/known_counts.py evaluate --data /tmp/tramcast-known-data --out /tmp/tramcast-known-model
```

Требуются неизменные raw, локальный аудит S-v2 и сохранённые контрольные
прогнозы 030 для четырёх cutoff. Никакой загрузки внешних данных и обучения
030 эти команды не выполняют. Из-за измерения wall_seconds манифест подготовки
при повторном запуске отличается; таблицы наблюдений должны совпасть побайтно.
Исследовательские окна ранее просмотрены — это не независимый конкурсный тест.
