# M20260927: проверка добавочной пользы признаков метро

**Заметного улучшения маршрутного прогноза не обнаружено.** Модель с числовыми
потоками метро численно неустойчива; её оценки на двух окнах не получены.
Ни один вариант не заменяет 030 и не доказывает остановочную точность.

Основной результат: [metro-20260927-v4/results.json](runs/metro-20260927-v4/results.json),
[manifest](runs/metro-20260927-v4/manifest.json),
[протокол до расчётов](METRO_PROTOCOL.md). Прежние результаты сохранены.

## Проверенная гипотеза

Расширена модель интенсивностей B20260927, обучаемая на московских маршрутных
суммах. Те же четыре маршрута, 315 позиций, Poisson likelihood, Gaussian priors
с SD=1 (интерсепты маршрутов SD=2), те же рабочие часы и маски наблюдения.

- `base`: сохранённая модель без новых признаков.
- `name`: явное упоминание метро в названии остановки, взаимодействия с утром,
  вечером и выходным. Это признак названия, а не подтверждённой пересадки.
- `flow`: `name` плюс индикатор доступности потока и стандартизированные
  log1p квартальных входов/выходов с теми же взаимодействиями. Используются
  только единственные кандидаты станция–линия с обоими счётчиками >0.

Для неизвестных признаков потока в матрице стоит центрированное среднее (0),
а отдельный индикатор отмечает отсутствие значения. Это заполнение **признака**,
не восстановление посадок и не превращение отсутствующего потока в нулевой.
Числовые признаки доступны 32 из 315 позиций (10,2%); 49 имеют явное имя метро,
17 соответствий неоднозначны и не получают числового потока.

Для cutoff 30.04, 30.06, 31.08, 31.10 взяты соответственно I, II, II, III
кварталы 2025. Снимок заморожен на весь 61-дневный прогнозный горизонт;
будущие факты не подставляются. Снимок также используется для всего обучения
в этой точке отсечения — не заявляется доступность признака на каждый день
истории. Даты публикации квартальных данных неизвестны, география поздняя,
связи по названиям не проверены на местности: это ретроспективный условный опыт.

## Результаты

WAPE по одним и тем же наблюдаемым маршрутным часам, проценты:

| Окно 2025 | base | name | flow | 030 |
|---|---:|---:|---:|---:|
| 01.05–30.06 | 18,5365 | 18,5368 | 18,5374 | 11,0659 |
| 01.07–30.08 | 26,0573 | 26,0469 | недоступно | 10,7392 |
| 01.09–31.10 | 13,9714 | 13,9638 | недоступно | 9,8309 |

Размеры масок — 4853, 4861, 4854 часа. Полнота регистрации не подтверждена;
это ошибка относительно наблюдаемых счётчиков, не истинного полного спроса.
MAE и пары факт–прогноз сохранены. Окна использовались в прежних исследованиях,
поэтому не являются новой независимой оценкой.

По заранее заданному выбору на первом окне остаётся `base`. Малые отличия
между base/name не интерпретируются как статистически значимые. Итоговый
профиль ноября–декабря с новыми признаками не выпускается: используется
ссылка на сохранённый B20260927-v4, runtime 030 не меняется.

Несмотря на почти одинаковую маршрутную ошибку, средняя TV остановочных долей
относительно base на первом окне составляет **14,79% для name и 39,89% для flow**.
У name на следующих окнах — 13,47% и 15,93%. Это расстояние между сценариями,
не измеренная ошибка распределения людей. Метрики остановок остаются null.

## Численная проверка

Новые параметры усилили трудности сходимости. Обычный старый оптимизатор
не сошёлся для flow. Метод с точной кривизной также не дал приемлемых решений.
Применён фиксированный переход к координатам на основе Fisher information,
BFGS и уточнение по аналитической кривизне. Это изменение численного решения,
а не likelihood, priors или данных. Начальная точка — вложенная базовая модель;
три старта различаются новыми коэффициентами. Проверяется абсолютный градиент.
Базовый контроль взят из прежнего численного расчёта; точный глобальный
оптимум ни для него, ни для новых моделей не доказан.

Все три name-фита прошли проверку; flow на первом окне — только один из трёх
стартов. Максимальный градиент принятых решений <4,1e−6. На двух следующих
окнах ни один flow-старт не прошёл проверку: WAPE/MAE записаны null со статусом
`failed_numerical_convergence`. Прогнозы этих решений не используются.

Запуски v1–v3 сохранены с исходниками и причинами остановки. v4 сохраняет
неудачу отдельного кандидата и продолжает остальные сравнения. Гипотезы и
критерий выбора после просмотра последующих окон не менялись.

## Вывод для продолжения

Результат не доказывает бесполезность метро как признака. Проверены лишь
32 однозначных по названию позиции в четырёх поздних схемах; реальная
доступность метро и историческое обслуживание неизвестны. Добавление таких
прокси способно заметно менять доли без проверяемого выигрыша.

Следующее содержательное обогащение — исторические входы метро и пешеходные
связи, схемы/обслуживание направлений, независимые остановочные наблюдения.
До них расширять число свободных пространственных коэффициентов в этой
постановке нет измеренного основания. BL–FS по-прежнему не обучается на
искусственных долях или маршрутных суммах, выданных за stop truth.
