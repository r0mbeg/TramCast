# Проверка переносимости E-network preflight

Локальные 884 256 строк прошли проверки баланса и формулы. Выпуск отклонён
для передачи: изолированная сборка через /tmp (символическая ссылка на
/private/tmp в macOS) остановилась при relative_to для пути исходника.
Нужна нормализация Path.resolve перед относительным хешированием.
Данные и исходник сохранены; схема prior и численные результаты не меняются.
