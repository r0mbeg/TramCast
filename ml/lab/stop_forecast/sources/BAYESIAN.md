# Байесовские подходы: поиск 27.09.2026

Проверены первичные источники; ниже разделены их модели и наша адаптация.
Ссылки получены веб-поиском и открытием страниц/PDF. Это методологические
источники, не исторические московские наблюдения.

- Nandi et al., 2023, [disaggregation](https://www.jstatsoft.org/article/view/v106i11),
  [полный PDF](https://www.jstatsoft.org/article/download/v106i11/4476).
  Прочитаны формулировка модели и priors, разделы 2–3. Локальные интенсивности
  с ковариатами суммируются в агрегатный likelihood. Gaussian priors сжимают
  коэффициенты; penalized-complexity priors ограничивают пространственное поле
  и эффекты агрегатов. Исследование эпидемиологическое; экспозиция — население,
  а не число трамвайных рейсов. Пространственное поле в наш минимальный опыт
  не перенесено: нет исторического московского эталона для проверки его пользы.
- Simpson et al., 2017, [PC priors](https://arxiv.org/abs/1403.4630).
  Просмотрены название и аннотация: prior задаётся через отклонение от простой
  базовой модели. Возможный следующий этап для дисперсии случайных эффектов;
  не реализован и не объявляется доказанным улучшением TramCast.
- [Stan: posterior prediction](https://mc-stan.org/docs/stan-users-guide/posterior-prediction.html),
  [predictive checks](https://mc-stan.org/docs/stan-users-guide/posterior-predictive-checks.html).
  Документация различает неопределённость параметров и будущих наблюдений,
  показывает Gamma–Poisson и проверку недостаточной дисперсии Poisson.
  Поэтому наши интервалы долей из Laplace не называются интервалами будущего
  количества посадок. Stan и новые зависимости не устанавливались.

## Применённая адаптация

[BAYES_PROTOCOL](../BAYES_PROTOCOL.md) фиксирует модель до расчёта. Poisson
с Gaussian prior в точке MAP — именно предложенная ранее L2-модель
интенсивностей; это две интерпретации одной оптимизационной задачи, а не два
независимых алгоритма. Второй likelihood — negative binomial с фиксированным
size=10. Оба используют реальные московские маршрутные суммы. Laplace
аппроксимация posterior рассчитывается для выбранного варианта; полноценного
MCMC и доказательства одномодальности нет. Prior маршрутных интерсептов
центрирован по обучающей истории (empirical Bayes), его неопределённость
не интегрируется.

Gamma–Poisson для интенсивности и Dirichlet для долей — полезный ещё более
простой контроль: если наблюдается только маршрутная сумма, независимый prior
на доли не обновляется. Это математическое свойство факторизованной модели,
а не отрицательный результат всех байесовских подходов. Общие признаки между
маршрутами дают дополнительные связи, но их достаточность требует проверки.

Нет обоснования переносить московские доли из Коломны либо выдавать поздний
географический снимок за историческую схему. Настоящая модель окружения
потребует исторических данных о населении/занятости, пересадках и обслуживании;
текущий опыт использует только географические прокси. Качество остановок
остаётся непроверенным даже при малой маршрутной ошибке.
