# ML-полигон TramCast

Здесь продолжается поиск моделей: подготовка данных, новые гипотезы, эксперименты,
временная оценка и разбор ошибок. `lab` не означает завершение исследований.
Рабочая реализация выбранного рецепта вынесена в `../runtime/`.

- `pipeline.py`, `model.py` — подготовка и контрольные модели; `dataset/` остаётся в корне репозитория.
- `experiments/`, `jobs/`, `tests/` — опыты, задания и проверки. Запускать из `ml/lab/`.
- `artifacts/`, `submissions/` — результаты и неизменяемые посылки, включая отрицательные результаты.
- Крупные промежуточные выгрузки новых опытов остаются локально по `.gitignore`; отчёты и исходники сохраняются в Git. Ранее отслеживаемые результаты при переносе не исключены.
- [Ключевые выводы](../docs/FINDINGS.md), [EXPERIMENTS](EXPERIMENTS.md), [SOLUTIONS](SOLUTIONS.md).
- [Исторические инструкции](HISTORY.md), [прежний контракт](RESEARCH_CONTRACT.md), [RESEARCH](RESEARCH.md).

Новый опыт сохраняется в отдельный каталог результатов с протоколом до расчёта;
законченные результаты не перезаписываются. Публикация в сервис — отдельный шаг:
зафиксировать подготовленные входы и проверки, затем перенести только необходимое
в `../recipes/` и рабочий расчёт в `../runtime/`. Сервис не импортирует исследовательские скрипты.

Старые отчёты сохраняют пути и контрольные суммы прошлых запусков. Локальная
подготовка теперь разрешает путь `dataset/` от корня репозитория; прежний
`pipeline.py` сохранён в `artifacts/source_snapshot_before_lab/`.
Старые копии `service.py`, `client.py`, `Dockerfile` и `forecast_bundle.json`
нужны для воспроизведения прежних измерений; актуальный запуск — [ML README](../README.md).

Локальные проверки: `python -m tests.test_pipeline`, `python -m tests.test_model`.
Зависимости каждого эксперимента и наличие GPU проверять по его инструкции.
Slurm-скрипты содержат прежние абсолютные пути; перенос локального каталога их
автоматически не обновляет. Не возобновлять старый поиск или отправки на платформу
только потому, что их команды сохранились в журнале.

Отдельный [CPU-опыт HistGradientBoosting](artifacts/cpu_hgb_20260927/REPORT.md):
полный прогноз с обучением за 1,07–1,33 с на локальном ARM64, пик процесса
214 МиБ; средний score 0,82085 против 0,88837 у сохранённого 030 на общей
маске четырёх окон. Рабочий рецепт не заменён, CPU-кандидат уступил по качеству.

[CPU-дистилляция 030](cpu_student/README.md) — отдельный CatBoost с командой
«любая дата начала 2025 → 61 день». Модель повторяет учителя приближённо:
5,60% WAPE на одной исключённой дате внутри фиксированного года; перенос
вперёд из ранних примеров слабее (14–23%). Начало года и 2026 — непроверенная
экстраполяция. Итоговые веса используют все семь дат учителя; это
ретроспективный ученик, не причинная историческая оценка и не замена runtime.

[Самостоятельный CPU-прогноз](cpu_forecast/README.md) обучен на реальных
наблюдениях из многих исторических стартов, без целей 030. На непрерывном
сентябре–октябре с обучением только по август score 0,85734 против 0,87418
у среднего с тем же правилом закрытия №50 и 0,89964 у 030. Итоговая модель
переобучена по октябрь и поставляется отдельно; основной runtime не переключён.

[LightGBM Laplace/L1](artifacts/lightgbm_laplace_20260927_v1/REPORT.md) на том же
CPU-пайплайне дал локальный score **0,87576** против **0,85734** у CatBoost;
новая посылка ноября–декабря сохранена отдельно. Закрытый score **0,85630**
сообщён пользователем для прежнего CatBoost; для LightGBM пользователь сообщил
**0,84716** — локальное улучшение не подтвердилось на закрытой проверке.

[Расширенная дистилляция v3](artifacts/dense_student_20260927_v3/REPORT.md)
обучена на 37 учительских стартах и реальных наблюдениях. CatBoost на CPU
дал **0,89853** против **0,89964** у GPU 030 на повторно использованной
сентябрьской проверке. Выдача всех 14640 часов — 0,107 с, отдельный процесс
181 МиБ, веса около 3 МБ на текущем Mac. Новая посылка сохранена отдельно,
пользователь сообщил закрытый score **0.88362**. Финальная компрессия включает ноябрьский
прогноз учителя: его fidelity не является независимой оценкой. Инструкция —
[dense_student](dense_student/README.md); модель подключена как основной CPU runtime на подготовленных признаках.
