## Как сохранять следующую попытку

1. Оценить фиксированную конфигурацию на обоих окнах; сохранить параметры, метрики и отчёт.
2. Сформировать отдельный прогноз ноября–декабря на истории января–октября, в том числе для неудачной новой попытки.
3. Выполнить `python archive_submission.py путь/к/submission.csv 004_daily_trend` (новое уникальное имя латиницей). Команда проверяет контракт и сохраняет исходные байты; существующее имя никогда не перезаписывает. При повторе эксперимента использовать следующий ID.
4. Добавить строку в этот индекс: объяснение, локальные оценки, ссылка на отчёт и CSV. Score сайта записывать только после реальной загрузки с указанием источника. Git фиксирует последующие обновления индекса.

Для 003: `python -m tests.test_weather_submission`, `python verify_weather.py`. Генератор `experiments/chronos_weather_experiment.py` также запрещает повторно использовать каталог результатов. `ml/submission.csv` менять только при принятии нового основного решения.
