# Основная CPU-модель

CatBoost dense-student-v3, закрытый score **0.88362** со слов пользователя.
Признаки подготовлены из истории до 1 ноября 2025; внешняя погода —
ретроспективный сценарий. Прогноз — 1 ноября–31 декабря, 14 640 часов.
Тяжёлый учитель участвовал в обучении; для работы этой поставки GPU не нужна.

- `features.csv` — 42 признака, дата и масштаб для каждого часа; не прогноз.
- `sources.json` — метаданные обучения, внешние снимки и контрольные суммы подготовки.
- `recipe.json` — неизменяемая конфигурация, хеши входов и нативных весов.
- `../../models/dense-student-v3.cbm` — веса отдельно от Git, 3 081 572 байта.

Основной запуск и ручное переключение: [HANDOFF](../../docs/HANDOFF.md).
Изменение истории/периода требует отдельного пакета, а не редактирования
существующей версии. Ранние даты 2025 с финальными весами ретроспективны;
качество произвольного нового периода этим выпуском не подтверждается.

Подготовка из корня репозитория (исследовательское окружение):

```sh
.venv-boost/bin/python -m ml.lab.dense_student.export_runtime \
  --bundle ml/lab/artifacts/dense_student_20260927_v3/bundle \
  --history ml/lab/artifacts/hourly_clean.csv --output /tmp/new-cpu-package
```

При переносе пакета проверьте относительный `model_file` в его конфигурации.
Runtime не импортирует подготовитель или другие лабораторные модули.
