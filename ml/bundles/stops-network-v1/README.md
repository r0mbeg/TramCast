# Профили остановочного распределения для runtime

Компактный экспорт неизменяемого `E-network-v1-dd0102fde9bb9667`:
604 позиции, 40 профилей на маршрут, период ноябрь–декабрь 2025.
Файлов готовых почасовых остановочных прогнозов здесь нет: `PredictStops`
распределяет фактические маршрутные целые значения сервиса.

`allocation_bundle.json` хранит хеши двух файлов и исходные метаданные.
`source_metadata` описывает исторический лабораторный выпуск; его поля
`integrated/published` не являются текущим состоянием сервиса. Актуальные
рабочие версии, включая хеш runtime-кода, выдаёт `service.py --describe`.

Пакет не перезаписывается. Новый выпуск создаётся офлайн через
`ml/preparation/export_stops.py`; инструкции, происхождение, ограничения
и порядок подключения Go — [STOPS_INTEGRATION.md](../../docs/STOPS_INTEGRATION.md).

сохранены в manifest. Это сценарные оценки без проверенной stop accuracy.
